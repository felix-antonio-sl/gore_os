Centro de Comando: ¿Un layout o tres?

¿Cuánta personalización visual necesita cada arquetipo? Misma estructura base, contenido diferente.

A

Layout Unificado

Un solo layout para todos: Atención → KPIs → Trabajo pendiente. Solo cambia el contenido según rol. Más simple, menos código, menos deuda.

B

3 Arquetipos Visuales

Supervisor (ADMIN_REGIONAL, JEFE_DIV), Ejecutor (ENCARGADO), Analista (DGI). Cada uno con layout distinto que refleja su modo de trabajo.

C

Layout Unificado + Módulos Opcionales

Misma estructura base pero con bloques condicionales: el supervisor ve "Mi Equipo", el ejecutor ve "Mi Progreso", el DGI ve "Indicadores".
