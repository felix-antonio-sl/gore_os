UX Journey Inbox — Enfoque B

6 cambios de alto impacto para Ejecutor + Supervisor

G1 CRITICO

ModuleMyProgress: de KPIs a Inbox

Journey J1 (Ejecutor). El ENCARGADO necesita ver SUS items pendientes con deadline, no solo conteos agregados.

ANTES

Mi Progreso

Completados4
Pendientes6
Vencidos2
Total10

Problema: Solo conteos. No se cual compromiso esta vencido ni cual vence primero.

DESPUES

Mi Trabajo

4/10 completados
Subsanar observaciones evaluacion MDSF -3d VENCIDO
Entregar informe avance Q1 programa DIDESO -1d VENCIDO
Coordinar reunion con municipio Chillan Viejo hoy
Revisar documentos licitacion puente Coihueco 3d
Completar satelites IPR 20240089 (partes, territorio) 5d
+ 1 item mas

Mejora: Items ordenados por urgencia, deadline visible, colores temporales, 1-click para navegar.

G8 ALTO

Done State: "Al dia"

Journeys J1-J4 (todos). Cuando el inbox esta vacio, el usuario necesita confirmacion positiva.

ANTES

(nada — el componente retorna null cuando items.length === 0)

El usuario no sabe si esta al dia o si el sistema fallo.

DESPUES

Al dia

No tienes tareas pendientes. Buen trabajo.

Mejora: Feedback positivo. El usuario sabe que termino su trabajo del dia.

G3 ALTO

Rendiciones: SLA Clock para RTF

Journey J3 (RTF). El RTF tiene SLA de 7 dias y necesita ver cuales estan por vencer.

ANTES
Codigo Convenio Monto Estado

DESPUES
SLA Codigo Convenio Monto Estado
6/7d
a3f8c2d1Conv. Muni Chillan$12.500.000EN_REVISION_RTF

A1 ALTO

Compromisos: dias restantes en lista

Journey J1 (Ejecutor). La lista actual muestra fecha cruda — necesita "en cuantos dias vence".

ANTES (columna Vence)
15/03/2026 Subsanar observaciones MDSF
18/03/2026 Coordinar reunion municipio
25/03/2026 Completar satelites IPR

Problema: Hay que calcular mentalmente cuantos dias faltan.

DESPUES (DeadlineCell mejorado)
hace 1 dia
15/03/2026
Subsanar observaciones MDSF VENCIDO
en 4 dias
18/03/2026
Coordinar reunion municipio
en 11 dias
25/03/2026
Completar satelites IPR

Mejora: "hace X dias" / "en X dias" + fecha original abajo. Colores: rojo vencido, amber <=7d, neutro >7d.
